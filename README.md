# سامانه آزمون آنلاین استاتیک

نام آزمون: **آزمون مرحله اول آمادگی آزمون تیزهوشان**  
زمان: **۶۵ دقیقه**  
شیوه نمره منفی: هر سه پاسخ غلط معادل یک پاسخ صحیح.

## حساب‌ها

- تست: `T` / `T` (امکان شرکت چندباره)
- دانش‌آموز: `stu` / `1234`
- مدیر: `ASHRAF` / `1234`

## تکمیل آزمون پس از دریافت PDF

1. فایل PDF فعلی در مسیر `assets/question1.pdf` قرار گرفته است.
2. آزمون فعلی شامل ۴۸ سؤال با شماره‌های نمایشی ۷۶ تا ۱۲۳ است.
3. کلید پاسخ در `answer-key.js` ثبت شده است. برای آزمون دیگر، پاسخ‌ها را به صورت اعداد ۱ تا ۴ وارد کنید؛ مثال:
   ```js
   window.ANSWER_KEY = [2, 1, 4, 3, 2];
   ```
4. برای آزمون‌های بعد، فایل‌هایی مثل `question2.pdf` اضافه کنید و مقدار `pdfFile`، عنوان، شناسه و کلید پاسخ را تغییر دهید.

## انتشار در GitHub Pages

محتویات پوشه را در یک Repository آپلود کنید. سپس از Settings → Pages، انتشار از شاخه `main` و پوشه root را انتخاب کنید.

## روند کارنامه

دانش‌آموز پس از پایان، فایل JSON نتیجه را دانلود و برای مدیر ارسال می‌کند. مدیر با حساب خود وارد شده و «ورود فایل نتیجه» را می‌زند. تحلیل و جدول نتایج در مرورگر مدیر نگهداری می‌شود.

## هشدار امنیتی مهم

این پروژه بنا بر انتخاب شما **کاملاً استاتیک** است. GitHub Pages بک‌اند ندارد؛ بنابراین:

- رمزها و کلید پاسخ در فایل‌های سایت قابل مشاهده‌اند.
- دانش‌آموز می‌تواند با پاک‌کردن Local Storage، مرورگر دیگر یا دستکاری JavaScript محدودیت یک‌بار شرکت را دور بزند.
- مدیر نمی‌تواند از راه دور آزمون یک دانش‌آموز را واقعاً باز یا بسته کند.
- فایل نتیجه JSON قابل دستکاری است و امضای رمزنگاری‌شده ندارد.
- این نسخه برای پیش‌نمایش، تمرین یا محیط کم‌ریسک مناسب است، نه آزمون رسمی.

برای امنیت واقعی، باید از Firebase، Supabase یا یک سرور اختصاصی استفاده شود؛ احراز هویت، زمان شروع، پاسخ‌ها، کلید و ثبت نتیجه باید سمت سرور انجام شوند.
